**LostFilmTrack** - это удобное расширение для браузера Chrome, которое позволяет быстро отслеживать новые выпуски сериалов и фильмов на популярном торрент-трекере LostFilm.

Все данные берутся из официального RSS-канала LostFilm:
https://www.lostfilm.download/rss.xml

Расширение читает RSS ленту напрямую, без использования сторонних прокси или серверов. Информация обновляется автоматически при каждом открытии окна расширения или при нажатии кнопки "Обновить".


*Почему не работает расширение?*

1.Проверьте подключение к интернету

2.Убедитесь, что сайт lostfilm.download доступен

3.Попробуйте обновить расширение на странице chrome://extensions/


**Установка**

1.[Скачайте](https://github.com/AlexanderRU44/LostFilmTrack/archive/refs/heads/main.zip))

2.Распакуйте ZIP архив

3.Откройте Chrome и перейдите на страницу расширений

4.Включите "Режим разработчика" (Developer mode) в правом верхнем углу

5.Нажмите "Загрузить распакованное расширение" (Load unpacked)

6.Выберите папку с расширением
